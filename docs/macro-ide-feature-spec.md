# 宏 IDE 辅助功能规格（Macro IDE Feature Spec）

本文只定义宏在 IDE 中**应当提供**的辅助功能，不描述任何仓库的实现状态。条目编号（`#N`）供设计与代码注释引用。

所有条目围绕同一条原则：让"展开前源码 ↔ 展开后代码"的因果关系在 IDE 中可见、可跳、可诊断。

## 1. 编写宏调用

1. `@` 后补全可用宏名，选中后自动补 `import <macro_package>.*`。
2. 调用点跳宏定义（Ctrl+B）、Find Usages 列出全部调用点、Quick Doc 展示宏签名与参数说明。
3. Quick Doc 标注该宏是否支持展开查看、是否可用于 debug 模式。
4. 宏 input 参数的语法高亮与校验：括号配对、token 合法性、参数个数。
5. 上下文约束提示：`assertParentContext` / `getChildMessages` 一类"必须嵌入某个外层宏"的规则。
6. 快速修复：缺失 import、宏包未编译、宏名拼写错误。

## 2. 展开查看

7. 展开光标处的单个宏。
8. 展开整个文件的全部宏，以列表形态呈现，每条可定位到对应调用点。
9. 递归展开 / 单层展开可切换；嵌套宏可逐层下钻。
10. 呈现形态三种备齐：
    - 弹窗 —— 快速一瞥，不占编辑器标签；
    - 只读虚拟文档 —— 主力形态，可搜索、复制、折叠、语法高亮；
    - diff —— 展开前后对比。
11. 展示元信息：宏名、调用点位置、展开引擎、是否命中缓存、耗时、诊断数。
12. 陈旧标记：源码已修改、展开结果未刷新时明确提示。
13. 展开结果可复制，可导出为文件。

## 3. 位置映射与导航

14. 展开块 → 调用点（点击锚点跳回源码）。
15. 调用点 → 展开代码中对应片段（反向高亮）。
16. 展开代码内部的符号跳转与 Find Usages。
17. 嵌套宏贡献着色：标明每段代码由哪一层宏生成。

## 4. 诊断与错误

18. 宏内 `diagReport` 发出的 error/warning 显示在**调用点**，包含 message 与 hint。
19. 展开后代码的编译/语义错误映射回调用点，并提供"跳到展开位置"。
20. 展开失败分类诊断，各自区分：宏包未编译、动态库缺失或加载失败、宏函数 panic、执行超时、引擎不可用。
21. 每类失败给 quick fix：编译宏包、重试、切换备用引擎、延长超时。
22. debug 模式已知限制提示：重排行列号导致换行敏感场景不适用、不支持宏定义内的宏调用、不支持带括号宏。
23. 同因诊断聚合：同一宏的多处调用产生相同错误时合并展示。

## 5. 宏作者侧

24. 宏定义结构识别与签名校验：`macro package` 声明、`public` 修饰、Tokens 参数与返回类型。
25. 分包约束校验：宏定义与宏调用不得同包，宏包必须先编译。
26. 宏函数自身调试：编译期执行时的日志输出、断点、单步。
27. 展开快照回归：对给定调用生成 golden 快照并支持对比。
28. 改宏前后的展开 diff：修改宏实现后，对比两次展开结果。

## 6. 调试

29. `--debug-macro` 一键构建开关（构建配置 / 运行配置中）。
30. `debugMacro` 运行配置：**断点落在展开后的代码上**。
31. 调试单步时，源码位置与展开位置双向跟随。

## 7. 工程与性能

32. 宏包编译调度：项目同步与文件变更时按需编译，产物缓存精确失效。
33. 展开缓存、并发请求去重、超时与取消、进度反馈。
34. 展开引擎选择与自动回退；引擎不可用时的降级路径。
35. 全局开关：自动展开、递归、缓存、超时、预览，供性能取舍。
36. `.macrocall` 产物的可见性与落盘策略（项目视图、编辑器标签、磁盘）。
37. 宏执行日志与可复制的排障信息（何时执行、耗时、失败原因）。

## 8. 语义集成

38. 展开结果参与补全 / 解析 / 类型推导，使宏生成的成员可被使用。
39. 结构视图 / 大纲显示宏生成的成员，并标注"由宏生成"。
40. 引用查找覆盖展开后的符号，且结果可映射回源码位置。
41. 失败降级：宏展开失败时不污染语义分析，行为退回展开之前。

## 9. 优先级

| 级别 | 内容 | 理由 |
|---|---|---|
| P0 | #7、#8、#14、#18、#19、#20、#21、#32 | 最小闭环：能看、能跳、能诊断 |
| P1 | #1、#2、#10（只读虚拟文档）、#12、#29、#30 | 日常可用性 |
| P2 | #24–#28、#38–#41 | 宏作者体验与语义天花板 |
