# 仓颉语言教程：从任务本开始

这份教程用一个命令行任务本作为主线。你会先写出能运行的 `.cj` 文件，再逐步加入任务列表、任务状态、类型建模、错误处理、包拆分、并发执行和边界调用。每一课都给出要完成的代码、检查点和练习，目标是让你能独立写出结构清楚的仓颉程序。

学习时不要跳过动手部分。仓颉有几个容易混淆的规则：`main` 不写 `func`，`if`、`match`、`try` 可以产生值，循环和赋值是 `Unit`，`class` 与集合是引用语义，`struct` 更适合表达独立值，跨类型转换必须显式写出来。这些规则只有放进小程序里才容易记住。

## 你会完成什么

第一阶段会得到一个能打印任务和处理命令行参数的小程序：

```cj
main(args: Array<String>) {
    if (args.size == 0) {
        println("taskbook: add | list | done")
        return
    }

    let command = args[0]
    let message = match (command) {
        case "add" => "准备新增任务"
        case "list" => "准备列出任务"
        case "done" => "准备完成任务"
        case _ => "未知命令"
    }
    println(message)
}
```

第二阶段会把字符串堆叠改造成结构化模型：

```cj
enum TaskStatus {
    | Open | Done
}

struct Task {
    public Task(let id: Int64, let title: String, let status: TaskStatus) {}

    public func isDone(): Bool {
        match (status) {
            case Done => true
            case Open => false
        }
    }
}
```

第三阶段会把程序拆成包，加入集合、泛型、异常、I/O 和并发。最后两课只处理宏与 FFI 的使用边界，让你知道什么时候该用、什么时候应该停住。

## 学习路线

1. 准备工具链：确认 `cjc`、`cjpm`、环境变量和目录。
2. 第一个命令行程序：写 `main`，编译，运行，传参。
3. 读懂源文件和入口：区分顶层、局部、成员、包声明和导入位置。
4. 值、变量和类型边界：掌握 `let`、`var`、`const`、显式转换、值语义和引用语义。
5. 表达式驱动流程：用 `if`、循环、`match` 和 `Nothing` 写清楚控制流。
6. 集合组织数据：用 `ArrayList` 和 `HashMap` 管理任务。
7. 函数和 Lambda：把重复流程抽出来，让调用点更稳定。
8. `struct` 建模值：用不可变值描述任务本中的核心数据。
9. `class` 与 `interface` 协作：把共享状态和抽象能力分离。
10. `enum`、`Option` 与 `match`：用类型表达缺失、分支和穷尽性。
11. 泛型复用组件：写可以复用在不同元素类型上的容器和函数。
12. 包和模块拆分：从单文件走向多包工程。
13. 异常和 I/O：处理失败路径，读写外部数据。
14. 并发任务：用 `spawn`、`Future` 和锁协调共享状态。
15. 宏的使用边界：理解宏输入输出是程序片段。
16. FFI 与 `unsafe`：把 C 边界隔离到小范围内。

## 阅读方式

每一课都按相同节奏组织：

- 目标：这节结束时你应该能做什么。
- 动手：直接修改或新增一段任务本代码。
- 关键语义：解释这段代码背后的语言规则。
- 检查点：用来判断你是否真正掌握。
- 练习：留一个小改造，让下一课有基础。

如果你已经会其他静态类型语言，可以略读解释，但不要跳过检查点。仓颉的表达式类型、入口函数、`Option`、模式匹配、泛型约束和并发语义都有自己的写法。
