## 新增需求

### 需求:表达式类型推断检查
系统必须检查表达式类型的可推断性。

#### 场景:无法推断表达式类型
- **当** 表达式的类型无法从上下文推断
- **那么** 必须报告 `UNABLE_TO_INFER_EXPR` 错误

### 需求:浮点字面量范围检查
系统必须验证浮点字面量是否在合法范围内。

#### 场景:浮点字面量超出范围
- **当** 浮点字面量值超出 Float32/Float64 的表示范围
- **那么** 必须报告 `EXCEED_FLOAT_LITERAL_RANGE` 错误

#### 场景:浮点字面量过大（警告）
- **当** 浮点字面量值接近最大表示范围
- **那么** 必须报告 `FLOAT_LITERAL_TOO_LARGE` 警告

#### 场景:浮点字面量过小（警告）
- **当** 浮点字面量值接近最小表示范围
- **那么** 必须报告 `FLOAT_LITERAL_TOO_SMALL` 警告

### 需求:一元运算符合法性检查
系统必须验证一元运算符操作数类型的合法性。

#### 场景:无效一元运算
- **当** 对不支持该一元运算符的类型执行运算
- **那么** 必须报告 `INVALID_UNARY_EXPR` 错误

#### 场景:一元运算返回类型不匹配
- **当** 一元运算的返回类型与期望的目标类型不匹配
- **那么** 必须报告 `INVALID_UNARY_EXPR_WITH_TARGET` 错误

### 需求:subscript 表达式合法性检查
系统必须验证 subscript 表达式的合法性。

#### 场景:无效 subscript 表达式
- **当** 对不支持 subscript 操作的类型执行下标访问
- **那么** 必须报告 `INVALID_SUBSCRIPT_EXPR` 错误

#### 场景:subscript 表达式不可赋值
- **当** 对不支持 subscript 赋值的表达式执行赋值
- **那么** 必须报告 `CANNOT_ASSIGN_TO_SUBSCRIPT` 错误

### 需求:成员访问合法性检查
系统必须验证成员访问的合法性。

#### 场景:非成员访问
- **当** 访问的名称不是指定类型的成员
- **那么** 必须报告 `NOT_MEMBER_OF` 错误

#### 场景:成员未导入
- **当** 访问的成员存在但未被导入
- **那么** 必须报告 `MEMBER_NOT_IMPORTED` 错误

### 需求:赋值合法性检查
系统必须验证赋值目标的可变性。

#### 场景:赋值给不可变值
- **当** 对不可变值（let 变量、不可变属性）执行赋值
- **那么** 必须报告 `CANNOT_ASSIGN_TO_IMMUTABLE` 错误

#### 场景:不合法的左值
- **当** 赋值操作的左值不是合法的赋值目标
- **那么** 必须报告 `UNQUALIFIED_LEFT_VALUE_ASSIGNED` 错误

### 需求:or-pattern 合法性检查
系统必须验证 or-pattern 中分支的一致性和变量引入限制。

#### 场景:or pattern 分支种类不一致
- **当** or pattern 的各分支使用了不同种类的模式
- **那么** 必须报告 `DIFFERENT_OR_PATTERN` 错误

#### 场景:or pattern 引入变量
- **当** or pattern 中的分支引入了变量绑定
- **那么** 必须报告 `VAR_IN_OR_PATTERN` 错误

#### 场景:or condition 引入变量
- **当** or condition 中引入了变量绑定
- **那么** 必须报告 `VAR_IN_OR_CONDITION` 错误

### 需求:不可达模式检查
系统必须检测不可达的模式分支。

#### 场景:模式不可达（警告）
- **当** 一个模式分支被前面的分支完全覆盖
- **那么** 必须报告 `UNREACHABLE_PATTERN` 警告

#### 场景:enum 构造器需要参数
- **当** 带参数的 enum 构造器在模式匹配中未提供参数
- **那么** 必须报告 `ENUM_CONSTRUCTOR_WITH_PARAM_MUST_HAVE_ARGS` 错误

### 需求:optional chaining 类型检查
系统必须验证 optional chaining 的接收者类型。

#### 场景:非 optional 类型使用 optional chaining
- **当** 对非 optional 类型使用 `?.` 操作符
- **那么** 必须报告 `OPTIONAL_CHAIN_NON_OPTIONAL` 错误

### 需求:变量初始化前捕获检查
系统必须检查变量在被捕获前是否已初始化。

#### 场景:初始化前捕获
- **当** 一个变量在初始化之前被闭包捕获
- **那么** 必须报告 `CAPTURE_BEFORE_INITIALIZATION` 错误

### 需求:常量模式中字符串插值检查
系统必须禁止在常量模式中使用字符串插值。

#### 场景:常量模式使用字符串插值
- **当** 模式匹配的常量模式中包含字符串插值
- **那么** 必须报告 `INTERPOLATION_IN_CONST_PATTERN` 错误

### 需求:包名引用限制
系统必须禁止独立引用包名。

#### 场景:独立引用包名
- **当** 代码中独立引用了一个包名（而非包中的成员）
- **那么** 必须报告 `CANNOT_REF_TO_PKG_NAME` 错误

### 需求:需要导入才能使用表达式
系统必须检查某些表达式是否需要先导入对应的包。

#### 场景:未导入即使用表达式
- **当** 使用某些需要特定导入的表达式但未导入
- **那么** 必须报告 `USE_EXPR_WITHOUT_IMPORT` 错误
