## 新增需求

### 需求:Unused 组全部诊断必须被覆盖
系统必须覆盖 `Unused` 组的全部诊断定义：`UNUSED_IMPORT`。

#### 场景:导入未被使用
- **当** 某个 import 在当前文件的有效语义范围内没有被使用
- **那么** 必须报告 `UNUSED_IMPORT`

### 需求:未使用导入只能在语义有效后报告
系统必须在确保导入解析和引用分析完成后再报告未使用导入。

#### 场景:引用分析尚未稳定
- **当** 导入解析或引用绑定尚未完成
- **那么** 不得提前报告 `UNUSED_IMPORT`
- **并且** 必须等待可判定的最终使用结果
