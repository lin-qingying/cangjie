## 新增需求

### 需求:最小 CFIR_RESOLVE 诊断入口
系统必须提供可执行的 CFIR_RESOLVE 入口与诊断收集链路，即便当前诊断集合为空。

#### 场景:空诊断输出可验证
- **当** 仅启用最小 CFIR_RESOLVE 骨架运行测试
- **那么** 诊断输出必须稳定且可对比（允许为空）

### 需求:最小诊断测试入口
测试基础设施必须支持最小 DiagnosticsHandler，用于验证 CFIR_RESOLVE 入口的诊断输出。

#### 场景:测试链路可运行
- **当** 运行诊断测试用例
- **那么** 测试框架必须完成 facade 与 handler 调用并生成诊断输出
