## 新增需求

### 需求:诊断测试接入测试基础设施
系统必须提供可复用的诊断处理器，使 resolve 诊断结果能够通过 test-infrastructure 的 `AnalysisHandler` 接口进行校验。

#### 场景:诊断处理器输出可比对结果
- **当** 诊断处理器收到解析产物与测试模块
- **那么** 处理器必须生成稳定的诊断输出并与 golden 文件进行比较

### 需求:resolve 诊断测试用例
系统必须提供最小诊断测试用例与对应的 golden 文件，用于验证 resolve 诊断链路可用。

#### 场景:最小诊断用例通过
- **当** 执行 resolve 诊断测试
- **那么** 测试必须读取 testData 中的源文件并与对应 diagnostics.txt 匹配
