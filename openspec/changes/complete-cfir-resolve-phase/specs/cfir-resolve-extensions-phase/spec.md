## 新增需求

### 需求:EXTENSIONS 阶段必须验证 extend 目标合法性
系统必须在 EXTENSIONS 阶段验证 extended type 是否可扩展、是否非法类型、是否错误地扩展接口目标。

#### 场景:非法 extended type
- **当** extend 目标是禁止扩展的类型形态
- **那么** EXTENSIONS 阶段必须产出非法扩展目标诊断

### 需求:EXTENSIONS 阶段必须验证实现接口集合合法性
系统必须检查 extend 声明中接口实现列表的重复、非接口目标、特化冲突，禁止仅执行重复文本检查。

#### 场景:extend 实现非接口类型
- **当** extend 的 inherited type 解析为非接口
- **那么** EXTENSIONS 阶段必须产出错误诊断

#### 场景:extend 特化冲突
- **当** 不同 extend 声明在实例化后实现相同接口版本
- **那么** EXTENSIONS 阶段必须产出冲突诊断

### 需求:EXTENSIONS 阶段必须执行跨包约束规则
系统必须执行扩展相关跨包约束（包含孤儿规则语义），禁止在跨包扩展场景中静默放过非法组合。

#### 场景:跨包非法扩展
- **当** 外部类型扩展外部接口且不满足规则约束
- **那么** EXTENSIONS 阶段必须产出规则违规诊断
