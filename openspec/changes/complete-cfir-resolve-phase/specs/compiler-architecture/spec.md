## 修改需求

### 需求:12 阶段流水线中的 CFIR_RESOLVE 必须是完整语义阶段
编译器架构必须将 CFIR_RESOLVE 定义为“从 Raw CFIR 到可语义消费 CFIR”的完整实现阶段，禁止将“最小可运行骨架”视为该阶段完成态。

#### 场景:架构文档与实现状态一致
- **当** 查询编译器阶段文档与模块实现状态
- **那么** CFIR_RESOLVE 必须被标记为完整语义实现目标，并给出明确输入/输出/验收边界

### 需求:CFIR_RESOLVE 与 FINALIZE/后端阶段职责必须严格分界
架构层必须明确 CFIR_RESOLVE 仅负责语义解析与 resolve 诊断，禁止将 FINALIZE、泛型实例化或后端职责混入 resolve 阶段。

#### 场景:阶段职责边界可验证
- **当** 在设计与实现评审中检查阶段职责
- **那么** 能够明确区分 resolve 与 finalize/backend 责任，且相关代码与文档无冲突定义
