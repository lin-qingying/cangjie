## 新增需求

### 需求:TYPES 阶段必须完成显式类型引用解析
系统必须在 TYPES 阶段解析声明头中的显式类型引用，包括参数类型、返回类型、字段类型、泛型参数约束类型。

#### 场景:函数签名显式类型解析
- **当** 函数声明包含显式参数类型与返回类型
- **那么** TYPES 阶段必须将对应类型引用解析为可消费语义类型或错误类型

### 需求:TYPES 阶段必须覆盖仓颉特有类型形态
系统必须支持仓颉类型语法中的 tuple、function type、VArray 及其他已定义特有类型形态，禁止将其统一降级为未支持错误。

#### 场景:VArray 类型解析
- **当** 声明中包含 `VArray<T, N>` 类型引用
- **那么** TYPES 阶段必须完成类型结构解析并为后续阶段保留维度与元素类型信息

### 需求:TYPES 阶段必须提供稳定错误恢复
系统必须在类型解析失败时构造稳定错误类型节点，并允许后续 STATUS/EXTENSIONS/IMPLICIT_TYPES 继续执行。

#### 场景:局部类型错误可恢复
- **当** 某声明类型引用无法解析
- **那么** TYPES 阶段必须产出诊断并以错误类型占位，而非终止后续阶段
