## 新增需求

### 需求:SUPER_TYPES 阶段必须构建继承图并验证基本合法性
系统必须在 SUPER_TYPES 阶段完成父类型关系构建，并检查自继承、重复父接口、接口继承类、多个类父类型等非法结构。

#### 场景:接口继承非接口
- **当** 接口声明继承一个类类型
- **那么** SUPER_TYPES 阶段必须产出错误诊断

#### 场景:类存在多个类父类型
- **当** 类声明中出现多个非接口父类型
- **那么** SUPER_TYPES 阶段必须产出错误诊断

### 需求:SUPER_TYPES 阶段必须支持泛型实例化后的重复接口检测
系统必须检测泛型实例化后形成的重复超接口，禁止仅按文本名称去重。

#### 场景:实例化后重复超接口
- **当** 两个不同声明路径在实例化后归约为同一接口类型
- **那么** SUPER_TYPES 阶段必须产出重复继承诊断

### 需求:SUPER_TYPES 阶段必须保留错误恢复能力
系统必须在发现继承错误后保留可继续解析的最小结构，禁止因单个声明错误中断全文件 resolve。

#### 场景:局部继承错误不中断文件解析
- **当** 文件中某个类型继承非法但其他声明合法
- **那么** 其余声明必须仍可继续推进到后续阶段
