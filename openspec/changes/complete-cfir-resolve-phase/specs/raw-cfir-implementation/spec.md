## 修改需求

### 需求:Raw CFIR 与 Resolve 的语义边界必须严格保持
Raw CFIR 构建阶段必须仅保留语法结构与未解析引用，不得在该阶段完成 resolve 语义绑定；所有语义绑定、类型求值与规则诊断必须在 CFIR_RESOLVE 执行。

#### 场景:Raw 输出不提前固化 resolve 结果
- **当** Raw builder 处理包含复杂类型与调用表达式的输入
- **那么** 输出必须保留未解析形态，且后续 resolve 阶段能够继续完成语义绑定

### 需求:Raw 阶段必须为完整 resolve 提供稳定输入契约
Raw 阶段必须为 resolve 提供稳定且信息充分的输入结构（源位置信息、类型引用形态、声明边界），禁止以丢失关键信息的简化结构作为过渡。

#### 场景:resolve 依赖信息完整可用
- **当** resolve 处理来自 Raw 的 `CfirDeclaration` 与 `CfirExpression`
- **那么** 必须能够获取完成语义解析所需的结构化输入，而不需要回退到 PSI 重新推断关键语法信息
