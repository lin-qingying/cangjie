## 新增需求

### 需求:IMPLICIT_TYPES 阶段必须完成声明边界类型推断
系统必须在 IMPLICIT_TYPES 阶段推断声明边界上的隐式类型（包括函数返回类型与可推断声明类型），禁止将该阶段保留为空推进。

#### 场景:函数返回类型隐式推断
- **当** 函数未显式声明返回类型且函数体可推导
- **那么** IMPLICIT_TYPES 阶段必须推断并写回稳定返回类型

### 需求:IMPLICIT_TYPES 阶段必须处理互相依赖与循环推断
系统必须处理声明间互相依赖的推断请求，并在无法收敛时产出循环推断诊断。

#### 场景:循环推断失败
- **当** 两个或多个声明形成无法打破的类型推断循环
- **那么** IMPLICIT_TYPES 阶段必须产出循环推断诊断并以错误类型恢复

### 需求:IMPLICIT_TYPES 阶段输出必须为 BODY_RESOLVE 提供稳定边界
系统必须保证 BODY_RESOLVE 不再重新定义声明边界类型，只消费 IMPLICIT_TYPES 结果。

#### 场景:BODY_RESOLVE 消费推断边界
- **当** 声明已完成 IMPLICIT_TYPES
- **那么** BODY_RESOLVE 必须在该边界上解析表达式并保持结果一致
