## 新增需求

### 需求:注释乱码扫描必须覆盖一方模块
系统必须扫描一方模块中的注释文本并排除 external/ 目录。

#### 场景:排除 external 目录
- **当** 执行注释扫描
- **那么** external/ 目录下的文件必须被排除

### 需求:注释乱码必须可追踪与可复核
系统必须生成可审计的清单，记录每条疑似乱码注释的位置与内容摘要。

#### 场景:生成清单
- **当** 执行注释扫描完成
- **那么** 必须输出包含文件路径与行号的清单

### 需求:乱码注释必须被修复为可读文本
系统必须对确认的乱码注释进行修复，修复后注释必须可读且不改变代码逻辑。

#### 场景:修复保持语义
- **当** 对乱码注释进行修复
- **那么** 注释语义必须保持不变且不引入代码逻辑变更
