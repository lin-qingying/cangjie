六、运行时异常详情（161 个非 Snapshot 失败）

🔴 ArrayIndexOutOfBoundsException（111 个） 最严重

症状：107 个无消息体，另有 3 个负数越界：Index -32755/−32753/−32751 out of bounds for length 40457

分布：主要在 CfirAnalysisMacroTestGenerated（Macro）和 CjcLlTArraylit5ErrorTest 中

根因推测：负数索引通常来源于整数溢出或 Short 转换后的负值被直接用作数组下标，可能在宏处理的 token offset 计算中存在符号位处理问题

🟠 IllegalStateException: Directive DIAGNOSTICS 作用域错误（10 个） 测试框架问题

症状：Directive DIAGNOSTICS has Global applicability but it declared in File

影响：全部在 CfirAnalysisLLTPsiTestGenerated$Extend$ExtendExport$DirectExtend 子套件下

根因：测试文件将 // !DIAGNOSTICS 指令放在了文件级别而非模块级别，导致测试框架拒绝解析

🟠 IllegalStateException: Macro 展开循环（8 个） MACRO_CYCLE

症状：Macro construction failed before CFIR test frontend output was produced. ERROR MACRO_CYCLE [CONSTRUCTION]: Macro expansion cycle detected for `Hide`

影响：全部在 APILevelChecker$Hide 下的 testCallHide2/3、testOverrideByHide34/35/61 等

根因：Hide 宏在 API 层级检查场景下产生了自引用展开循环，宏展开器未正确处理此类递归情况

🟡 IllegalStateException: 模块内重复文件名（4 个） 测试数据问题

症状：File with name "hide.cj" already defined in module mix_macro1_use.cj / mix_macro2_use.cj

根因：测试数据中同一模块下出现了同名文件 hide.cj，可能是测试 case 生成时引入了重复文件

🟡 IllegalArgumentException（12 个） 分析异常

症状：FileAnalysisException 包裹 IllegalArgumentException，涉及文件：

  • EnvVarsConfigurationSource.cj:614 × 2
  • string_interpolation_01.cj:10:22 × 2
  • and.cj:9:9，and2.cj:9:9，and.cj:9:16 等

根因：逻辑运算符（and/or）和字符串插值处理中传入了非法参数，可能是 PSI 节点类型校验不严格

🟡 AssertionError: 标记顺序错误（5 个） 测试框架问题

症状：Another not done marker added after this one. Must be done before this.

根因：测试框架内部的 "done marker" 机制：前一个任务未完成时又添加了新任务，属于测试框架并发/顺序问题
