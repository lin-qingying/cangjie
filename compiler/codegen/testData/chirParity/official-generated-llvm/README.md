This directory stores offline baseline text generated by the official Cangjie compiler.

Current baseline scope:
- `basic/*.txt`
- `advanced/*.txt`

Generation command (from repo root):

```powershell
powershell -ExecutionPolicy Bypass -File compiler\codegen\testData\chirParity\tools\generate-official-llvm-baselines.ps1
```

Generate only a sub-directory (recursive):

```powershell
powershell -ExecutionPolicy Bypass -File compiler\codegen\testData\chirParity\tools\generate-official-llvm-baselines.ps1 -FixtureSubdir basic
```

Generate optimized baseline sets:

```powershell
powershell -ExecutionPolicy Bypass -File compiler\codegen\testData\chirParity\tools\generate-official-llvm-baselines.ps1 -OptimizationLevel O1 -OutputRootDirName official-generated-llvm-o1
powershell -ExecutionPolicy Bypass -File compiler\codegen\testData\chirParity\tools\generate-official-llvm-baselines.ps1 -OptimizationLevel O2 -OutputRootDirName official-generated-llvm-o2
```

Advanced scenarios typically need a companion source file (same relative path as
fixture, but with `.cj`) because fixture metadata alone is not enough to
reconstruct a compilable source program. Place companion files at either:

- `compiler\codegen\testData\chirParity\<relative>\sample.cj` (next to fixture), or
- `compiler\codegen\testData\chirParity\tools\official-sources\<relative>\sample.cj`

The test `OfficialCompilerLlvmIrComparisonTest` reads these files and compares them
against LLVM IR generated by this project.

Notes:

- The generator compiles with `--save-temps` and uses `*.opt.bc` as source of truth.
- For fixtures that declare unresolved foreign symbols (for example `importedCall`
  and `voidCall`), linker failure is tolerated if `.opt.bc` exists, and generation
  continues.
