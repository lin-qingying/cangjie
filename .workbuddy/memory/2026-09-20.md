- **InitializationCheck（10 unique）**：核心是「被 throw 终止的赋值不构成初始化」的定值分析
  （`c = throw Exception()`、`a = Some(1) ?? throw Exception()`），外加「终止语句后的语句不可达」
  （case 042 里 CFIR 还把 `a = 2` 误报成 CANNOT_ASSIGN_TO_IMMUTABLE）、static init 内自引用（`x = Foo.y`）、

  `variable_use_before_init_03` 是 range 项，官方 `sema_mismatched_types_multiple_assign` 锚 RHS
  `(1, 2, 3)`（L4 C18→C27），fixture 正确、CFIR 锚整个赋值。

  `REDECLARATION` / `INVALID_SUBSCRIPT_EXPR` / `BUILTIN_INDEX_IN_BOUND` 等噪声，且缺整体
  `TYPE_MISMATCH` 与 `TUPLE_PATTERN_NOT_MATCH`；需要「LHS 作为元组模式 + 元素目标」的语义，属独立特性。
